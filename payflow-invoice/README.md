## Notes

- The pages are independent from the existing PhoneCheck Pro root pages.
- Copy claims match the current PayFlow Invoice MVP: local storage, PDF invoice export, local follow-up reminders, no login, no ads, no analytics, no backend sync, and no payment processing.
- If the final App Store name changes to DueFlow Invoice, update page titles, headings, and metadata before submission.
